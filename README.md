# Smart Recycle Assistant

Trợ lý AI hỗ trợ phân loại và tái chế rác thải tại nguồn.

## Thành viên
- A: AI/Data
- B: Backend
- C: Frontend/UI + Báo cáo

## Cấu trúc
- `ai/`: dữ liệu, notebook huấn luyện, mô hình
- `backend/`: API FastAPI
- `frontend/`: giao diện người dùng
- `docs/`: báo cáo, use case, wireframe

## Quy ước làm việc
- Không push thẳng lên `main`, làm trên nhánh `feature/...` rồi tạo Pull Request.
- Không commit file `.env` và bộ dữ liệu ảnh.
